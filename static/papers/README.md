# Seminar Papers: Local LLMs for Translation

Core reading materials for the 90-minute seminar on local LLMs and translation.

## Papers

| File | Citation | Topic |
|------|----------|-------|
| `zhu_2024_llm_translators.pdf` | Zhu et al. (2024). "Large Language Models are State-of-the-Art Translators." arXiv:2401.01319 | Comprehensive evaluation of LLMs on translation tasks, showing SOTA performance |
| `goyal_2022_flores101.pdf` | Goyal et al. (2022). "The Flores-101 Evaluation Benchmark for Low-Resource and Multilingual Machine Translation." arXiv:2106.03193 | Evaluation benchmark with 101 languages, useful for in-session evaluation |
| `briggs_prompting_llm_mt.pdf` | Briggs et al. "Prompting Large Language Models for Machine Translation." arXiv:2004.03017 | Prompting strategies and techniques for MT tasks |
| `hallucinations_llm_translation.pdf` | "The Curious Case of Hallucinations in LLM Translation." arXiv:2305.11008 | Analysis of hallucination patterns in LLM-generated translations |
| `llm_quality_estimation_mt.pdf` | "Translation Quality Estimation with LLMs." arXiv:2309.08209 | Using LLMs for automatic quality estimation of translations |

## Usage in Seminar

- **Pre-reading for instructors**: All papers
- **Handouts for students**: Flores-101 paper (for evaluation exercise), Zhu et al. (for overview)
- **Discussion basis**: Hallucinations paper (critical discussion on limitations)
